## The entry

`main.py` writes one one-line excuse for a missed deadline to `/output/entry.txt`:

> I didn't miss the deadline — I rescheduled it in my head and forgot to CC the deadline on the invite.

The excuse is built for the judge brief: it really is an excuse for a missed
deadline, it is a single sentence that reads cleanly aloud, the punch lands at
the end (the deadline itself never got the invite), and the angle is fresh —
no dog ate it, no traffic jam, just a reschedule the deadline was never told about.

## Running

```sh
python3 main.py   # writes the excuse to /output/entry.txt
```
